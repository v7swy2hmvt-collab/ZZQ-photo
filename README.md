# 中国古镇图鉴 / China Historic Towns Atlas

一个基于原始 HTML 名录改造的中英双语、可公开部署的静态网站。

## 本地预览
直接双击 `index.html` 通常即可打开；如果浏览器限制本地资源，建议在本目录运行：
`python3 -m http.server 8000`
然后访问 `http://localhost:8000`。

## 公开部署
### GitHub Pages
1. 新建 GitHub 仓库。
2. 上传 `index.html`、`data.js`、`README.md`。
3. 在仓库 Settings → Pages 中选择部署分支和根目录。
4. 保存后使用 GitHub Pages 提供的网址访问。

也可把这三个文件上传到 Netlify、Cloudflare Pages 或其他静态托管平台。

## 内容与注意事项
- 原文件中的 110 条古镇/古城名录、中文简介、坐标、地区和专题标签均已保留。
- 页面支持中文/英文界面切换、名称/省份/城市搜索、地区筛选、专题筛选、地图标记和弹窗。
- 英文介绍是根据专题标签生成的概括性说明，并非逐条权威翻译；原始中文简介仍在详情中显示。
- 地图和 Leaflet 依赖在线资源，访问网站时需要网络连接。
- 地理坐标沿用原文件，个别位置可能不精确；名录中的历史描述建议发布前核验。
